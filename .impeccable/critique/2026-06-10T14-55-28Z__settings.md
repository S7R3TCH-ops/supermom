### Anti-Patterns Verdict

**LLM assessment**: Follows the app design system reasonably well (pink borders, dark hero, SectionLabel, Fraunces in hero). The real failures are architectural: jargon copy, missing form fields, dark-mode breakage. The eyebrow "✦ System Settings" is the banned kicker-on-every-section pattern.

**Deterministic scan**: 1 finding — transition: height at line 363 (keyboard spacer). Intentional app-wide pattern; known acceptable trade-off.

### Overall Impression

Functional and mostly consistent with the design system, but four DB fields (address, city, postal_code, signature) are initialized in form state and written on save but have no input elements. Postal code goes on invoices. That's a real gap. Copy register also consistently uses system-speak.

### What's Working

1. Section structure is clear. Preferences → Integrations → Team → Security is a logical flow.
2. Error prevention on destructive action: confirm before reset plus warning text.
3. GCal integration row: CONNECTED/NOT CONNECTED status and CONNECT/RECONNECT button swap is unambiguous.

### Priority Issues

**[P1] Missing form fields — address, city, postal_code, signature have no inputs**
postal_code appears on invoices (added v0.12.14). address + city feed invoice address block and maps routing. signature is the AI profile tone. All four are initialized from DB and written on save — bad initial data is locked in forever.
Fix: Add input rows for Address, City, Postal Code under the business profile section. Signature in a collapsed "AI Profile" row.

**[P1] Dark mode: hardcoded background: 'white' on all four cards**
Produces bright white cards on dark #1C1C1E page background in dark mode. Every other page had dark mode cards fixed in v0.12.22; Settings was missed.
Fix: Replace background: 'white' with background: T.surface ?? 'white'.

**[P1] Copy register: "Config & Profile" / "System Settings" are system-speak**
Sandra runs a personal services business. "Config & Profile" and "✦ System Settings" sound like an OS settings panel.
Fix: Hero kicker → drop it or "✦ Your Business". Hero heading → "Settings". Remove eyebrow kicker pattern.

**[P2] Native checkbox for Tax Calculation toggle**
Raw 18×18 browser checkbox is visually inconsistent next to styled controls everywhere else.
Fix: Replace with styled toggle-switch component.

**[P2] SAVE SETTINGS buried with no unsaved-changes signal**
Non-technical user changes name at top, gets distracted, scrolls away — change lost silently.
Fix: Either auto-save on blur, or show sticky "Unsaved changes" indicator when form diverges from business.

### Persona Red Flags

**Sandra (Solo Operator)**: Opens Settings, changes HST number, doesn't realize she must scroll to bottom to tap SAVE. Change lost. Never reports it.

**Casey (Distracted Mobile)**: Taps avatar to change it, native file picker launches, leaves app during upload — no loading state on the avatar circle itself during upload.

**Riley (Stress Tester)**: No maxLength on any input — very long business name saves and will overflow invoice heading.
