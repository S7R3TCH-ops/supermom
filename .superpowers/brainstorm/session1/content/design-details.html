Design: Standardizing Supermom v2.0

Architecture for the Hybrid TypeScript + Tailwind v4 Upgrade

1. Core Styling Engine: Tailwind v4

We will replace the current CSS variables and Tailwind v3 setup with Tailwind v4. This version is built on Lightning CSS, meaning the styling is processed instantly with zero runtime cost.

CSS-First Config

Theme tokens (colors, fonts, radii) move from tailwind.config.js to standard CSS variables in index.css. This is the new production standard.

Runtime-Free

Removes the need for heavy JS-based theme calculation, speeding up first-paint on mobile devices.

2. Typographic Standard Components

Instead of scattered styles, we'll implement a strictly typed component library in src/components/ui using TypeScript (.tsx).

Proposed Components
  • <Text />: The base primitive. Handles body, caption, and metadata styles.
  • <Heading />: Handles Display, H1, H2, and H3 levels using Fraunces.
  • <Label />: Replaces SectionLabel with standardized uppercase tracking and weight.

3. Migration Strategy

New Standard

  • All new components in .tsx
  • Strict prop definitions
  • Tailwind v4 utility classes

Interoperability

  • Existing .jsx files import these TSX components seamlessly
  • Incremental migration: we only convert existing files when we touch them for features
