> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix calendar timeline clipping, add Home "Today" pill, add job cancellation with reason for all users, and add admin-only hard-delete for jobs and archive for clients.

**Architecture:** All changes are additive UI layer on top of existing data patterns. `cancelJob` and `archiveClientJobs` are new repo functions. Role gating uses `profile.role` from the existing `useAuth` hook. No schema migrations — cancellation reason stored in `ai_context` JSONB.

**Tech Stack:** React 18 (Vite), Supabase JS client, inline styles (no CSS modules), existing hooks (`useAuth`, `useToast`, `useSwipeToDismiss`).

In `src/data/jobsRepo.js`, after the `softDeleteJob` export, add:

```js
export async function cancelJob(id, reason) {
  const businessId = await getCurrentBusinessId();
  const { data: current } = await supabase
    .from('jobs')
    .select('ai_context')
    .eq('id', id)
    .eq('business_id', businessId)
    .single();

  const { data, error } = await supabase
    .from('jobs')
    .update({
      job_status: 'Cancelled',
      updated_at: new Date().toISOString(),
      ai_context: {
        ...(current?.ai_context || {}),
        cancellation_reason: reason,
        cancelled_at: new Date().toISOString(),
      },
    })
    .eq('id', id)
    .eq('business_id', businessId)
    .select()
    .single();
  if (error) throw error;
  assertWrote(data, 'cancelJob');
  return decorateJob(data);
}
```

- [ ] **Step 2: Add `archiveClientJobs` after `cancelJob`**

```js
export async function archiveClientJobs(clientId) {
  const businessId = await getCurrentBusinessId();
  const { error } = await supabase
    .from('jobs')
    .update({ deleted_at: new Date().toISOString() })
    .eq('client_id', clientId)
    .eq('business_id', businessId)
    .is('deleted_at', null);
  if (error) throw error;
}
```

                      <button

                        style={{ flex: 1, background: T.card, border: `1px solid ${T.cardBorder}`, borderRadius: 9, padding: '9px 0', fontFamily: T.font, fontSize: 12.5, fontWeight: 600, color: T.inkSub, cursor: 'pointer' }}
                      >
                        Cancel
                      </button>
                      <button
                        onClick={handleArchive}
                        disabled={archiveBusy}
                        style={{ flex: 1, background: '#B01550', border: 'none', borderRadius: 9, padding: '9px 0', fontFamily: T.font, fontSize: 12.5, fontWeight: 700, color: 'white', cursor: archiveBusy ? 'not-allowed' : 'pointer', opacity: archiveBusy ? 0.7 : 1 }}
                      >
                        {archiveBusy ? 'Archiving…' : 'Archive Everything'}
                      </button>
                    </div>
                  </>
                )}
              </div>
            )}
          </div>
        )}

        <div style={{ height: 8 }} />
      </div>
